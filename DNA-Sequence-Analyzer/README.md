\# DNA Sequence Analyzer



\## Project Overview

A beginner-level Python project to analyze DNA sequences and calculate nucleotide composition.



\## Objective

To understand basic Python programming through a bioinformatics application.



\## Features

\- Accepts a DNA sequence from the user

\- Converts the sequence to uppercase

\- Checks whether the sequence contains valid DNA bases

\- Calculates sequence length

\- Counts A, T, G, and C nucleotides

\- Calculates GC content and AT content percentages



\## Technologies Used

\- Python

\- Git

\- GitHub



\## Sample Input

`ATGCGCAT`



\## Sample Output

| Parameter | Result |

|---|---:|

| Sequence Length | 8 |

| A Count | 2 |

| T Count | 2 |

| G Count | 2 |

| C Count | 2 |

| GC Content | 50% |

| AT Content | 50% |
